## 📺 Supported Devices

- Android TV
- Google TV
- Android Phones
- Android Tablets
- Android TV Boxes
- Amazon Fire TV (Sideload)
- Android Emulators

---

## 🚀 Installation

1. Download the APK that matches your device.
2. Enable **Install unknown apps** in Android settings if required.
3. Open the downloaded APK and install it.
4. Launch the app.
